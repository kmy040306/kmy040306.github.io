# 고단백 제품은 효율적인 단백질 공급원인가?

**팀원** A: 윤석주 · B: 권민영

바를 하나 고를 때 포장에 적힌 단백질 함량만 보면, 같은 열량으로 단백질을 얼마나 섭취하는지 알기 어렵습니다. 이 프로젝트는 바·떠먹는 요거트·유제품 기반 음료에서 **단백질을 강조하는 제품**과 일반 제품을 비교합니다. 같은 열량당 단백질이 얼마나 더 들어 있는지, 그 차이와 함께 당류·나트륨·포화지방·열량은 어떻게 달라지는지 살펴봅니다.

[프로젝트 페이지](https://kmy040306.github.io/) · [분석 튜토리얼](https://kmy040306.github.io/final/tutorial.html) · [분석 노트북](final/tutorial.ipynb)

## 무엇을 비교하나요?

- **비교 대상**은 식품군이 같은 제품입니다. 바와 요거트의 영양성분은 100g당, 음료는 100mL당 비교합니다.
- **단백질 강조 여부**는 포장이나 제조사 공식 설명에서 확인합니다. 표시 근거가 충분하지 않은 제품은 주분석에서 제외합니다.
- **분석 단위**는 제품 시리즈입니다. 같은 브랜드·제품 라인에서 맛만 다른 제품은 묶고, 제품별 지표를 먼저 계산한 뒤 시리즈 안에서 평균을 냅니다.
- **단백질 효율**은 100kcal당 단백질 양입니다. 같은 기준량의 단백질(g)을 열량(kcal)으로 나누고 100을 곱합니다.

## 가설과 검증 방법

| 구분 | 가설 또는 분석 질문 | 검증 방법 |
| --- | --- | --- |
| 주가설 | 같은 식품군에서 단백질 강조 시리즈의 평균 단백질 효율이 더 높다. | 양측 Welch t 검정으로 평균 차이를 검정하고, 강조 집단에서 일반 집단을 뺀 차이가 양수인지 확인합니다. |
| 부가설 | 당류·나트륨·포화지방·열량의 평균은 두 집단에서 각각 차이가 있다. | 같은 식품군 안에서 네 지표를 각각 Welch t 검정으로 비교합니다. |
| 확장 가설 | 단백질 효율의 집단 차이는 식품군마다 다르다. | 시리즈 평균 효율을 대상으로 단백질 강조 여부와 식품군의 상호작용을 회귀모형으로 탐색합니다. |

먼저 식품군과 집단별 시리즈 수, 분포를 확인합니다. 주가설과 부가설의 검정은 Holm 방식으로 함께 보정하고, 평균 차이와 95% 신뢰구간을 보고합니다. 시리즈를 다시 뽑는 부트스트랩으로 평균 차이의 불확실성을 한 번 더 살펴봅니다.

## 예측과 사례 비교

- **머신러닝**은 당류·나트륨·포화지방만으로 처음 보는 시리즈의 단백질 강조 여부를 예측할 수 있는지 확인합니다. 식품군별로 로지스틱 회귀와 깊이 3 결정트리를 만들고, 시리즈 단위 층화 5겹 교차검증에서 다수 집단 기준 모델과 비교합니다. 균형 정확도와 단백질 강조 집단의 F1 점수로 평가합니다.
- **사례 비교**에서는 식품군별 효율 상위 단백질 강조 시리즈와 삶은 닭가슴살·삶은 계란·두부를 살펴봅니다. 단백질 20g을 섭취할 때 필요한 식품의 양과 함께 섭취하는 열량·당류·나트륨·포화지방을 비교합니다.

## 분석 결과

확정 데이터 `v001`에서 제품 118개를 92개 시리즈로 묶어 분석했습니다. Holm 보정 후 바와 유제품 음료의 단백질 강조 집단은 일반 집단보다 평균 효율이 높았습니다(각각 100kcal당 +3.56g, +8.39g). 요거트는 일반 24개·강조 10개 시리즈를 비교했으며, 평균 효율 차이는 불확실했습니다.
