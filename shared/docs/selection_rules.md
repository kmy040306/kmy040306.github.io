## 1. 식품군 범위

예비 조사 결과, 바는 전용 분류 코드가 사실상 없고(`시리얼바/에너지바/영양바` 13건) 프로틴 음료 대부분은 우유 코드가 아닌 `액상음료`에 있다. 따라서 분류 코드와 제품명·원재료 규칙을 함께 쓴다.

### bar — 기준 100g
- 포함 분류(대표식품명): 시리얼바/에너지바/영양바, 일반과자, 초콜릿과자, 견과류 가공품, 견과류, 기타 농산가공품, 기타가공품, 시리얼, 두류가공품
- 제품명 조건: 프로틴바·단백질바·에너지바·시리얼바·그래놀라바·견과바·영양바 등 바 형태 이름, 또는 대표식품명이 `시리얼바/에너지바/영양바`
- 제외: 초콜릿 캔디바(초콜릿·카라멜·누가가 주재료인 일반 초코바, 예: 스니커즈류), 분말, 쿠키·웨이퍼, 빙과·아이스크림, 기준량 100ml
- 예비 후보 약 478행, 이 중 제품명에 단백질 키워드 약 189행 (규칙 확정 전 수치)

### yogurt — 기준 100g
- 포함 분류: 발효유, 농후발효유, 크림발효유
- **기준량 100g 행만 사용.** 100ml로 기록된 떠먹는 요거트는 환산하지 않고 제외(`reason_code=basis_unit`), 한계로 보고
- 제외: 마시는 요거트(이름에 드링크·마시는 등), 냉동 디저트, 요거트 토핑 과자
- 일반·그릭 모두 포함, `yogurt_style`(plain/greek)을 기록하고 해석 시 구성 차이를 명시
- 예비 후보 100g 약 1,255행(드링크 이름 58행 포함, 제외 전)

### dairy_drink — 기준 100ml
- 포함 분류: 우유, 우유(멸균), 가공우유, 가공우유(멸균), 강화우유, 유당분해우유, 유함유가공품 + **액상음료**

## 2. 단백질 강조 판정 (protein_claim)

- 1: 포장 또는 제조사 공식 설명에서 고단백·프로틴·단백질 ○g 등을 제품 특징으로 강조
- 0: 포장·공식 설명을 검토했으나 강조 없음
- 빈칸(미상): 근거 부족 → 주분석 제외, 일반으로 바꾸지 않음
- 영양정보 표의 단백질 수치나 **제품명 키워드만으로 판정하지 않는다.** `evidence_url`, `checked_at`, `claim_text` 기록

## 3. 시리즈와 추출

- 시리즈: 동일 브랜드·동일 라인에서 맛만 다른 제품. 강조/일반 라인, 제형·핵심 배합이 다르면 분리. 브랜드 전체를 묶지 않음
- 중복: 같은 제품명+제조사가 여러 행이면(예비 후보에서 69행) 영양값이 같으면 최신 `데이터기준일자` 1행만 남기고, 다르면 정제 로그에 기록 후 공동 판정
- **이름 기준 층화 추출**: 식품군마다 제품명에 `프로틴|단백질|고단백|protein`이 있는 시리즈(선별층 1)와 없는 시리즈(선별층 0)로 나눈다. 층마다 최대 30시리즈를 시드 42로 무작위 추출하고, 시리즈 안 맛 제품은 최대 3개를 시드 42로 추출한다
- 제품명 키워드는 **추출용 선별 기준일 뿐**이며 최종 집단은 2절의 포장 확인으로 정한다. 선별층과 최종 집단이 다른 사례 수를 보고한다
- 후보 목록은 정렬·보존하고 영양값 결과를 보기 전에 추출한다
- 식품군 유지: 효율 계산 가능 시리즈가 양 집단 각각 10개 이상이면 추론 분석 포함, 미만이면 기술통계·사례로 제한

## 4. 단위·결측

- 영양성분 함량 기준량을 사용. 포장 중량·1회 섭취참고량을 분모로 쓰지 않음. 100g↔100ml 환산 없음
- 예비 후보에서 주요 성분의 빈칸은 없고 0은 존재(포화지방 333행, 당류 44행 등). 표시 기준상 0 표기가 허용되므로 **0은 표시된 값 그대로 유지**하고, 결측·미량·검출한계 표기가 나오면 원값을 보존하고 결측 처리. 평균 대체 없음
- 효율 = 단백질 / 열량 × 100 (g/100kcal). 분모 0·결측이면 계산하지 않음
